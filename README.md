# Unraveling_Method_Thesis
master equation unraveling numerical methods for solving quantum open systems dynamics

Each File is dedicated to a particular system, but the simulation scheme is the same. If you are dealing with a finite algebra you can explicitly simplify the evolution operator as done in "Driven_linear_H.ipynb".

The file "Multiple_higher_orders_H_comparison" has a cell where the full numerical scheme is defined as a function and can be used to compare different Hamiltonians.
